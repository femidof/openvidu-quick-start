# Openvidu & Livekit Flutter QuickStart

This app implements a video room using Openvidu or LiveKit's Flutter SDK. Designed to run for iOS, Android, Web, Mac, and Windows.

## Quickstart

Run example:

```bash
flutter pub get
# Due to the inconvenience of typing on mobile devices, 
# you can autofill URL and TOKEN for first run in debug mode.
flutter run 
```

## Environment Variable 
They are available at ```utils.dart``` change those variables to your suit.
